Study 1 · Mouse visual cortex · Done

Does knowing what a mouse is doing help predict what its brain sees?

A model that sees only the picture, against one that also knows the mouse’s pupil size and running speed.

The answer: yes, in all three mice. Adding pupil and running raised held-out prediction by +0.032 to +0.049, about 25–34% more than the picture alone. This is prediction, not proof of cause.

How we tested it

The same steps for every mouse, scored on images the model never saw.

  • The picture

    Shrunk and summarised

    Each image is shrunk 4×4 and summarised with 150 principal components.

  • The behaviour

    Pupil and running

    Pupil size and running speed recorded at the same moment as the brain activity.

  • The model

    Ridge regression

    One simple model per neuron, standardised on training data only.

  • The test

    Official held-out images

    Scored by the correlation between predicted and real activity, averaged over neurons.

  • The data

    Sensorium 2022

    Public recordings from mouse primary visual cortex, thousands of neurons per mouse.

  • The unit

    Each mouse counts once

    Neurons are not treated as separate animals.

The results

Result

Every mouse is predicted better with behaviour.

The picture alone explains part of what visual cortex does. Knowing whether the mouse is alert and running explains more, in all three animals.

Mean held-out Pearson correlation across neurons, Sensorium 2022 official test images.

Gain

The size of the gain differs by mouse.

Pupil size helps all three animals. How much running adds changes from mouse to mouse, so each animal is reported on its own.

Gain = score with behaviour minus score with the picture only.

Trying to break the result

Three checks that could have made the gain disappear.

  • Shuffle the behaviour

    Almost no gain

    Behaviour scrambled across trials, 20 times per mouse, adds almost nothing. The gain needs behaviour from the same moment.

  • Leave one mouse out

    Still positive

    The average gain stays positive whichever mouse is removed, so no single recording carries the result.

  • Pupil or running?

    Pupil helps every mouse

    Taking each signal away in turn: pupil improves all three mice; running varies by animal.

Leave one mouse out

Positive without any one animal.

This makes the three-mouse pattern less dependent on one recording. It is a check, not an estimate for all mice.

Average gain over the two remaining mice.

Code and data

The analysis is in AmishI123/neuroscience-project (notebooks 01–05 and src/summarize_replication.py). The numbers here are copied from its committed summary into website/build_results.py. Data: Willeke et al. (2022), The Sensorium competition on predicting large-scale mouse primary visual cortex activity, arXiv:2206.08666.

What it does not show

Three mice cannot speak for all mice. A better prediction does not show that arousal or running cause the change. The report’s intervals are within each animal, not for the whole population.
