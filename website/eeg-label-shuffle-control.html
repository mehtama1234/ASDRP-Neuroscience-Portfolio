What happens when the labels are shuffled?

A pre-specified control disconnects the eye-state labels from the EEG values, then reruns the same five forward-chaining folds used by the main analysis.

CONTROL DESIGN

We globally permuted the 14,980 labels 20 times with seed 20261108. Each permutation uses the same chronological folds, feature construction, and class-balanced logistic-regression pipeline. The control asks whether the evaluation produces a chance-level result when the signal/label relationship is intentionally broken.

How to interpret it

The shuffled controls are near chance, as expected. This supports treating the observed time-series result as dependent on the actual labels rather than a generic artifact of the pipeline. It does not establish generalization to new participants, and it does not turn one recording into a population study.

Scope: one continuous UCI EEG recording; this is a negative-control result, not a clinical or diagnostic claim.
