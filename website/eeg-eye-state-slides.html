ASDRP / EEG eye stateResearch slides

01 · THE QUESTION

Does short-term history help decode a neural state?

We test whether causal temporal context improves classification of open-eye versus closed-eye state from 14-channel EEG.

02 · THE DATA

14 channels. 14,980 chronological samples. One continuous recording.

The UCI EEG Eye State dataset provides EEG values and a manually annotated binary label.

03 · THE EVALUATION

Time order matters.

We use 70% train, 15% validation, and 15% final test blocks. No random row split allows neighboring samples to leak across partitions.

04 · THE BASELINE

Pointwise EEG reaches:

0.625

held-out test ROC AUC, with balanced accuracy 0.557.

05 · THE EXTENSION

Temporal context reaches:

0.530

held-out test ROC AUC after adding causal nine-sample trailing means and standard deviations.

06 · THE LESSON

Validation improvement did not guarantee test improvement.

The context model looked slightly better on validation but worsened on the untouched final block. The negative result stays in the report.

07 · THE NEXT TEST

More recordings. More timescales. Better generalization.

This proof-of-method study should be extended with additional recordings and blocked cross-validation before making subject-level claims.
