ASDRP / mouse visual cortexResearch slides

01 · THE QUESTION

Does behavioral state help us predict the brain?

A mouse can see the same image twice, but its visual cortex may respond differently depending on internal state.

02 · THE DATA

Three recordings. Thousands of neurons. One held-out protocol.

Sensorium 2022 provides natural-image stimuli, neural responses, pupil size, change in pupil, and running speed.

03 · THE COMPARISON

Same held-out test. One added question.

AStimulus-only ridge model
BStimulus + behavior ridge model

04 · THE RESULT

Behavior improves the prediction.

0.126stimulus only
0.158stimulus + behavior

The behavior-augmented model improves all three evaluated mice: 0.126 → 0.158, 0.154 → 0.203, and 0.143 → 0.191.

05 · THE ABLATION

Pupil carries the gain here.

0.127stimulus + running
0.158stimulus + pupil
5.4%running trials

06 · THE LIMIT

A result is not a universal law.

Three evaluated animals. Correlational prediction, not causation. The next experiment is replication beyond three animals with population-level uncertainty.

07 · THE NEXT TEST

Replication before generalization.

Pre-specify the four model comparisons, preserve training-only preprocessing, summarize animals hierarchically, and report failed or low-quality runs.
