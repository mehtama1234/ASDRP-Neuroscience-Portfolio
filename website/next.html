Chapter 5 · What comes next

Five experiments, one for each link in the story.

Each one gets its analysis written down before it runs, a test on data kept aside, a check that could break it, and an honest write-up, just like chapters 2 and 3.

The five experiments

  • 1 · Planned · tests chapter 2

    Does the timing matter?

    Does behaviour from the same moment predict better than behaviour from a moment nearby? Needs the raw Sensorium recordings, which are not in this repository.

  • 2 · Ready to run · tests chapter 3

    Brain-wave bands

    Alpha waves rise when eyes close. Do bands like alpha hold up over time better than raw signals? Uses the EEG file already here.

  • 3 · Planned · tests chapter 2

    Which neurons care?

    Is the gain spread across all neurons, or held by groups chosen in advance by depth and position? Needs raw responses and neuron positions.

  • 4 · Started · tests chapter 3

    Why does it drift?

    How fast does the link between signal and eye state change, and does adjusting for drift help? Block-by-block scores and the glitch check are done.

  • 5 · Planned · tests chapter 4

    Do the apps help?

    Do one-step-at-a-time designs make tasks easier to finish? Needs consent, a task list written in advance and no personal data beyond what the test needs.

The rule we keep: a plan stays labelled as a plan until it has code, saved results, a rerun record, its limits written down and a page like the two studies.
