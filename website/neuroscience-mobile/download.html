The same five chapters, as an Android app.

The app is built straight from the phone tour on this website, so the words, numbers and pictures are the same. It is a test build for reviewers, not a store release.

Download the Android app →Use it in the browser instead

Before you install

  • Step 1

    Download the file

    Tap the button above on an Android phone. The file ends in .apk.

  • Step 2

    Allow this one install

    Android asks before installing apps from outside the store. Say yes for this file only.

  • Check it

    Same file as the code

    Every new tour is built by GitHub from the repository. Its fingerprint (SHA-256) is in SHA256.txt.

What it is not

It does not collect anything, does not need an account and does not diagnose anyone. It explains the research, one screen at a time.

iPhone and iPad

Open the phone tour in Safari and choose Share, then Add to Home Screen. It works the same way.
