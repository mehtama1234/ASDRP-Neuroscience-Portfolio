UCI EEG EYE STATE · TIME-AWARE CLASSIFICATION

Does short-term history help decode a neural state?

A second project tests whether causal temporal context improves classification of open-eye versus closed-eye state from 14-channel EEG.

BASELINE

Pointwise EEG

0.625held-out test ROC AUC

Standardized channel values at each time point, evaluated on the final chronological 15% of the recording.

EXTENSION

EEG + context

0.530held-out test ROC AUC

Causal nine-sample trailing means and standard deviations did not improve generalization in this recording.

WHY IT MATTERS

Negative results count

The context model looked slightly better on validation but worsened on the final test block. Keeping that distinction protects the study from overclaiming.
