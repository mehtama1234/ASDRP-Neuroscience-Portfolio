# Mouse visual-cortex artifact package

This folder is the first project-specific communication package for the flagship
Sensorium study.

## Included

- `index.html` — self-contained interactive research explainer.
- `mobile-demo.md` — mobile experience specification derived from the existing
  `neurocomms` mobile patterns.
- `../neuroscience-mobile/` — working responsive mobile demo covering both the
  mouse and EEG studies, with printable research cards.
- `presentation-outline.md` — slide and presenter structure.
- `video-script.md` — five-minute research walkthrough script.

The current result values come from `neuroscience-project/docs/REPORT.md`. They are
presented as reported results, not as a substitute for replication.
