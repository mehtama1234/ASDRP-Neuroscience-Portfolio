# Mobile demo specification

The mobile companion should reuse the copied `neurocomms` interaction patterns:
large tap targets, one focused task per screen, clear progress, local-first
behavior, and a visible scope note.

## Screen flow

1. **Question** — “Does behavior help us predict the brain?”
2. **Choose a model** — stimulus only or stimulus + behavior.
3. **See the result** — one large correlation number and a plain-language sentence.
4. **Explore the ablation** — pupil, running, or both.
5. **Check the limits** — three evaluated mice, correlational result, population
   generalization still open.
6. **Take the research card** — export a compact summary for a presentation or
   application review.

No participant data or clinical inference is needed for this demo. It is an
educational interface over the published project results.
