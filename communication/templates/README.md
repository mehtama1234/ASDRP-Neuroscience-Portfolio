# Reusable communication templates

These are copied source templates from the existing `neurocomms` and
`neuro-divergent` projects. They establish the artifact formats for the ASDRP
portfolio; project-specific text and figures will be added as separate copies so
the originals remain unchanged.

## Included

- `neurocomms-web/` — exact PhraseBench-style static landing page.
- `neurocomms-mobile/` — mobile project metadata, acceptance materials, and
  Capacitor configuration.
- `neurocomms-presentation/` — HTML presentation surfaces, video surface, and
  example PDF exports.
- `neurodivergent-theme/` — exact communication-tool CSS/theme files, including
  the mobile experience rules and Fraunces-oriented theme conventions.

## How we will use them

1. Keep these files as reference templates.
2. Copy each template into a project-specific artifact folder.
3. Replace only the content, figures, and project links.
4. Preserve the established interaction, accessibility, and limitations patterns.
5. Verify every HTML, PDF, mobile, and video artifact before linking it from the
   portfolio site.
