# Neural state and attention

Planned complementary study using a public EEG or physiological dataset.

The project will ask whether signal features can distinguish attention, workload,
or other cognitive states while maintaining a simple and interpretable baseline.

Required evidence before calling this project complete:

- A documented dataset and preprocessing pipeline
- A baseline model and a stronger comparison model
- Held-out evaluation
- Error analysis and limitations
- A report, interactive visualization, and presentation
