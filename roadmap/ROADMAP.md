# End-to-end roadmap

## Phase 1 — Foundation

- Finalize the portfolio narrative.
- Audit the flagship notebooks and report.
- Replace placeholders and document authorship.
- Add reproducibility and data provenance notes.

## Phase 2 — Stronger science

- Replicate the visual-cortex result across more animals.
- Add ablations, uncertainty, and held-out statistical evaluation.
- Separate exploratory findings from confirmatory claims.

## Phase 3 — Research expansion

- Select one complementary neural-state project.
- Complete its baseline, main experiment, report, and figures.
- Decide whether the biological/artificial vision comparison is a third project or
  an extension of Project 1.

## Phase 4 — Product and communication layer

- Build the portfolio website.
- Build interactive research dashboards.
- Package the neurodivergent and Neurocomms work as applied neurotechnology.
- Create the presentation and research videos.

## Phase 5 — Application package

- Select the strongest research story.
- Finalize reports, essays, figures, and links.
- Record the overview and flagship videos.
- Test every public link and demo from a fresh browser.
- Prepare a clear explanation of personal contributions and limitations.

## Completion standard

A project is complete when a reviewer can understand the question, inspect the
method, see the result, try the demo, read the limitations, and reproduce the
main analysis without needing a private explanation.
