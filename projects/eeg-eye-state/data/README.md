# Data provenance

`EEG Eye State.arff` was downloaded from the official UCI Machine Learning
Repository dataset page:

https://archive.ics.uci.edu/dataset/264/eeg%2Beye%2Bstate

The dataset is attributed to Oliver Roesler (2013) and is distributed under the
Creative Commons Attribution 4.0 International license. The project does not add
participant data or claim clinical significance.
