# Neurodivergent tools

The `neuro-divergent` work is the applied, human-centered side of the portfolio.
It explores tools for communication, accessibility, planning, and community support.

For the ASDRP portfolio, this work should be presented through concrete design
decisions, accessibility evaluation, user needs, and careful privacy boundaries—not
unsupported medical claims.

Live app: [Next Step](https://mehtama1234.github.io/neuro-divergent/) (the source repository is private). Portfolio page: [Tools for people](../website/tools.html).
